## Финальный проект 7 спринта

## <h>API сервиса Яндекс Самокат</h>
Тестирование API сервиса Яндекс Самокат. Его документация: qa-scooter.praktikum-services.ru/docs/.


Протестированы ручки:
- Создание курьера
- Логин курьера(авторизация)
- Создание заказа
- Список заказов




### <h>1. Установите зависимости:</h>

> pip install -r requirements.txt</h>

### <h>2. Запустить все тесты и записать отчет:</h>

> pytest --alluredir=./allure-results

### <h>3. Посмотреть отчет по прогону html</h>

> allure serve ./allure-results
